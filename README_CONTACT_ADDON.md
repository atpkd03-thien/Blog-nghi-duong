# Cài đặt liên hệ

Sau khi áp dụng migration `site_settings_contact_brand`, vào:

`/admin/settings`

Có thể thay đổi:
- Số điện thoại
- Link Zalo
- Link Facebook
- Tên thương hiệu
- Tagline

Thông tin liên hệ được dùng ở trang chủ, footer, mobile CTA và trang chi tiết dự án.

## Supabase

Migration đã được áp dụng trực tiếp cho project hiện tại. Nếu triển khai project mới, chạy phần `site_settings` trong `supabase/schema-projects.sql`.
